# avadge-novelty

Claude Code / Claude Desktop skill: публикация «Новинок» (премьер) в каталог AVADGE.

Учит модель собирать поля автомобиля, раскладывать фотографии в принятом порядке
(перед 3/4 мордой влево → борт → корма → руль → салон), отправлять машину в
`management API` и проверять карточку через MCP-сервер `avadge`. Цена всегда
запрашивается у человека, публикация — тоже его решение: скилл создаёт черновик.

## Установка

Скопируй папку в один из каталогов скиллов:

```bash
# для одного проекта
cp -r avadge-novelty <project>/.claude/skills/

# для всех проектов
cp -r avadge-novelty ~/.claude/skills/
```

Дальше скилл подхватывается автоматически — по описанию во frontmatter.

## Что нужно рядом

- MCP-сервер `avadge` (тулы `novelty_*`) — для проверки и публикации карточки.
- Ключ API в `X-Api-Key` / `$AVADGE_API_KEY` — для создания машины. В репозитории
  ключей нет и быть не должно.
