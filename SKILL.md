# Публикация новинки в каталог AVADGE

Новинка — это премьера: машины ещё нет в наличии, она живёт в отдельном разделе
`/api/v1/catalog/search/?section=novelty` и намеренно скрыта из обычного каталога и
из фида «в наличии». Технически это `Car` с `novelty=true`.

Две вещи, из-за которых чаще всего получается брак, и почему они важны:

1. **Созданная машина невидима.** `Car.published` по умолчанию `False`, а лента новинок
   отдаёт только `published=True`. Создание — это черновик. Публикует **пользователь**,
   отдельным словом, после того как посмотрит карточку глазами. Сам не публикуй.
2. **Порядок фотографий = порядок отправки.** Галерея читается `order_by('id')`, то есть
   в том порядке, в каком фото залиты. Переставить потом можно только через админку,
   поэтому порядок нужно собрать правильно ДО отправки.

## Ход работы

1. Собери данные машины (таблица полей ниже). Чего не хватает — **спроси**, не выдумывай.
2. **Цену спроси у пользователя всегда.** Её нельзя вывести из объявления или прикинуть
   по рынку: это наша продажная цена, её назначает человек.
3. Разложи фотографии в правильном порядке (раздел «Фотографии»).
4. Отправь `POST /management/api/create_car` (multipart, если файлы локальные).
5. Проверь результат через MCP: `novelty_get_novelty(id)` — сверь `photo_count` и
   `gallery_urls`, они покажут, все ли фото доехали и в каком порядке.
6. Покажи пользователю, что получилось, и жди его «публикуй» → `novelty_update_novelty(id, published=true)`.

## Поля машины

Обязательные — без любого из них ручка вернёт 400:

| Поле | Тип | Заметки |
|---|---|---|
| `mark` | строка | Марка. **Должна уже существовать в БД** (58 марок), иначе 400. |
| `model_name` | строка | Модель, например `X5`. Если такой модели у марки нет — создастся автоматически. Альтернативы: `model_id` (pk существующей) или legacy `model`. Нужно ровно одно из трёх. |
| `year` | int | Год. |
| `price` | int | Рубли, **минимум 4 500 000** (валидатор модели). Спрашивается у пользователя. |
| `engine_volume` | float | Литры: `3.0`. Если прислать кубсантиметры (`2993`), backend сам поделит на 1000. Для электрички — `0`. |
| `power` | int | Л.с. |
| `probeg` | int | Км, **максимум 190 000**. У премьеры почти всегда `0`. |
| `engine_type` | строка | См. справочники ниже. |
| `body` | строка | То же. |
| `drive` | строка | То же. |
| `transmission` | строка | То же. |
| `exterior_color` | строка | То же. |
| `descriptions` | текст | Именно с `s` на конце. Описание комплектации по-русски. Не сочиняй опции, которых нет в источнике — лучше коротко и правдиво. |
| `export_country` | строка | Страна экспорта, **должна существовать в БД**. |
| `main_photo` | файл или URL | Главное фото, обязательно. |
| `novelty` | bool | **`true`** — иначе машина уедет в обычный каталог, а не в новинки. MCP-тул проставляет сам; при отправке curl'ом это твоя ответственность. |

Необязательные, которые обычно пригождаются: `modification` (`40d xDrive M Sportpaket Pro`),
`interior_color`, `country` (страна-производитель), `in_stock_price`.

Не трогай без просьбы: `published` (публикует пользователь), `in_stock`, `hit`, `sale`,
`configurator`, `retro_auto`.

## Справочники значений

Backend нормализует эти поля сам: сравнивает первые 5, затем первые 3 символа с русской
подписью и с английским ключом. Поэтому проходят и `Дизель`, и `diesel`, и `дизельный`.
Значение, которое не совпало ни с чем, даёт 400 со списком допустимых — это не тупик,
просто выбери из списка.

- **engine_type:** Бензин `petrol` · Дизель `diesel` · Электричество `electric` · Гибрид `hybrid`
- **transmission:** Механика `manual` · Автомат `automatic` · Вариатор `cvt` · Полуавтомат `semi-automatic`
- **drive:** Передний привод `fwd` · Задний привод `rwd` · Полный привод `awd`
- **body:** Седан `sedan` · Хэтчбэк `hatchback` · Универсал `universal` · Внедорожник `suv` ·
  Минивен `minivan` · Кроссовер `crossover` · Купе `coupe` · Пикап `pickup` · Родстер `roadster` ·
  Кабриолет `cabriolet` · Лифтбэк `liftback` · Лимузин `limuzin`
- **exterior_color / interior_color:** Белый · Чёрный · Синий · Красный · Серебристый · Серый ·
  Зелёный · Коричневый · Бордовый · Бежевый · Оранжевый · Терракот · Голубой · Фиолетовый ·
  Лиловый · Желтый · Золотой

**Страны экспорта** (`export_country`) — берутся из справочника, новые сами не создаются:
Австрия, Бельгия, Великобритания, Германия, Италия, Канада, Китай, Корея, Нидерланды, ОАЭ,
Польша, Румыния, США, Франция, Чехия, Швеция, Эстония, Япония.

**Марки** — тоже только существующие: AC, Acura, Alfa Romeo, Alpina, Aston Martin, Audi,
Bentley, BMW, Bugatti, Cadillac, Chevrolet, Citroen, Cupra, Dacia, Daihatsu, Dodge, Ferrari,
Fiat, Ford, Genesis, GMC, Honda, Hyundai, Ineos, Infiniti, Jaguar, Jeep, Kia, Lamborghini,
Land Rover, Lexus, Lincoln, LiXiang, Lotus, Maserati, Mazda, McLaren, Mercedes-Benz, Mini,
Mitsubishi, Morgan, Nissan, Opel, Pagani, Peugeot, Polestar, Pontiac, Porsche, RAM,
Rolls Royce, Skoda, SsangYong, Subaru, Suzuki, Toyota, Volkswagen, Volvo, Zeekr.

Если нужной марки или страны в списке нет — не подставляй похожую, скажи пользователю:
запись заводится в админке, иначе машина привяжется не к той марке и потеряется в фильтрах.

## Фотографии

Порядок не косметика: первое фото — это обложка карточки в ленте новинок, следующие три
человек листает, не открывая галерею. Поэтому за первые четыре кадра нужно рассказать
машину целиком: как выглядит спереди, сбоку, сзади и внутри.

Порядок отправки:

1. **Главное фото — перед в три четверти, машина развёрнута мордой влево.** Видно передок
   и левый борт, корма чуть уходит вправо. Это канонический ракурс всех карточек AVADGE,
   именно он делает ленту однородной.
2. **Борт целиком, желательно левый.** Если левого борта в наборе нет — правый, это не брак.
3. **Корма.**
4. **Салон, начиная с руля** — кадр с рулём и приборкой.
5. **Дальше остальной салон** — торпедо, экран, передние сиденья, задний ряд.
6. Всё прочее (детали, диски, багажник, подкапотка) — в конце, порядок свободный.

Если какого-то ракурса нет — не подставляй вместо него другой и не оставляй дырку в
последовательности: просто пропусти его и сдвинь остальные. Лучше три правильных кадра,
чем четыре, где на месте кормы стоит колесо.

Когда ракурс на фото непонятен, посмотри на изображение (Read по файлу или URL), а не
угадывай по имени файла: `IMG_4821.jpg` не говорит ни о чём, а порядок из-за ошибки
исправляется только руками в админке.

## Отправка

Ключ: заголовок `X-Api-Key`. Это тот же ключ, которым ходит MCP — отдельный заводить не
нужно. Достань его в переменную и дальше используй только её:

```bash
AVADGE_API_KEY=${AVADGE_API_KEY:-$(python3 -c "import json;print(json.load(open('.mcp.json'))['mcpServers']['avadge']['headers']['Authorization'].split()[1])")}
```

Подставляй ключ **переменной, а не текстом**: команда с ключом внутри попадает в историю
шелла и в логи, а ещё её может зарубить проверка безопасности. И никогда не вписывай ключ
в файлы репозитория и в текст ответа пользователю.

Локальные файлы (обычный случай — фотографии лежат на диске):

```bash
curl -X POST "https://avadge.com/management/api/create_car" \
  -H "X-Api-Key: $AVADGE_API_KEY" \
  -F "mark=Porsche" -F "model_name=Cayenne" -F "modification=Turbo GT" \
  -F "year=2026" -F "price=25900000" \
  -F "engine_volume=4.0" -F "power=660" -F "probeg=0" \
  -F "engine_type=Бензин" -F "body=Кроссовер" -F "drive=Полный" \
  -F "transmission=Автомат" -F "exterior_color=Серый" \
  -F "export_country=Германия" \
  -F "descriptions=Комплектация Turbo GT, пакет Sport Chrono, керамика." \
  -F "novelty=true" \
  -F "main_photo=@/path/01-front34.jpg" \
  -F "photo_urls=@/path/02-side.jpg" \
  -F "photo_urls=@/path/03-rear.jpg" \
  -F "photo_urls=@/path/04-wheel.jpg"
```

Повторяющийся ключ `photo_urls` — это и есть галерея; порядок аргументов = порядок в
карточке. Ответ: `{"id": 1531, ...}`.

Если фотографии уже лежат в интернете, тот же запрос можно отправить JSON'ом, где
`main_photo` — строка-URL, а `photo_urls` — массив строк; Django скачает их сам. Ровно это
делает MCP-тул `novelty_create_novelty_car`, и им удобно пользоваться, когда локальных
файлов нет.

## Проверка и публикация

Скачивание фотографий на стороне Django **падает молча**: недоступная ссылка или ответ не
с картинкой просто пропускается, машина при этом создастся. Поэтому после создания всегда
дёрни `novelty_get_novelty(id)` и сверь `photo_count` с тем, сколько отправлял. Если не
сходится — скажи пользователю, каких кадров не хватает, и перезалей их через админку.

Дальше покажи пользователю карточку (марка, модель, цена, число фото, порядок первых
четырёх) и остановись. Публикация — его решение:

```
novelty_update_novelty(id=1531, published=true)
```

Этот же тул правит `in_stock_price`, `novelty` и `descriptions`. Всё остальное (фото,
характеристики) правится только в админке — если пользователь просит поменять что-то ещё,
так и скажи, не изобретай обходных путей.

## Ошибки

- **400 с перечислением допустимых значений** — не совпал справочник (`engine_type`, `body`,
  `drive`, `transmission`, цвет). Выбери значение из списка.
- **400 «не найден в списке допустимых»** — марки или страны нет в БД. Нужна админка.
- **400 по `price`** — меньше 4 500 000. Уточни цену у пользователя, не «подгоняй» её.
- **401/403** — ключ не передан или отозван.
- **404 от `novelty_get_novelty` / `novelty_update_novelty`** — машина существует, но у неё
  `novelty=false`: эти ручки работают только с новинками. Значит при создании потерялся
  `novelty=true`.
